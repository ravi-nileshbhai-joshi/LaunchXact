## Template 2: Reddit Comment Formula ("Value-First, Soft-Plug")
**Goal**: Comment on Reddit posts to answer questions while introducing your SaaS without getting banned.

### The Structure
1. **Direct Answer / Empathy**: Validate their problem first.
2. **Actionable Advice**: Give 2-3 bullet points of instructions they can use *without* buying anything.
3. **The Soft-Plug**: Mention your tool as a specialized solution, disclosing your bias.

## Template 5: AI FAQ Schema Template (GEO/AEO Optimization)
**Goal**: Structured Q&As to help ChatGPT, Gemini, and Perplexity crawl and cite your product.

### JSON-LD Script (Place in `<head>`)
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "How does [Your SaaS Name] solve [Main Problem]?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[Your SaaS Name] helps users [Main Problem] by [explain key mechanism/workflow in 2 sentences]. This eliminates the need for [painful alternative]."
      }
    },
    {
      "@type": "Question",
      "name": "What is the difference between [Your SaaS Name] and [Competitor Name]?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Unlike [Competitor Name] which requires [negative aspect], [Your SaaS Name] focuses on [your main hook/simplicity/speed], offering [specific benefit]."
      }
    }
  ]
}
</script>
```

## Template 6: High-Converting Homepage Formula
**Goal**: The exact section-by-section structure of a high-converting landing page.

### The Structure
1. **Hero Section**: 
   - Headline: Outcome-based hook.
   - Subheadline: How it works + target customer.
   - Primary CTA: Clear action ("Start Free Trial", "Get Instant Access").
   - Social Proof: "Trusted by 100+ developers."
2. **The Empathy Section**: "Does this sound familiar?" points addressing current frustrations.
3. **The Outcomes Section**: 3-4 cards showing *how their life changes* after using your product (not features).
4. **The Product Demo / Inside look**: Interactive dashboard preview or high-quality video walkthrough.
5. **Social Proof / Testimonials**: Wall of love or curated quotes.
6. **Pricing / Waitlist**: Unambiguous plans.
7. **FAQ**: Address objections and optimize for SEO/AEO.
